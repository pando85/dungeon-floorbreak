## Import

Unzip at the repository root on `design/f03-over-city-bible`. The files are already arranged beneath `assets/concept/floor-03/`. Check existing paths before overwriting. **No existing files should be overwritten.** This ZIP is intentionally separate from the text-only PR because binary assets are not committed there yet.

## Agent treatment

1. Read `docs/02-art/floor-03-over-city-art-direction.md` in PR #246, then the global art bible, antihero tone, and approved Carl/Donut/Mongo source references.
2. Use this art to discuss overall **environment composition only**. Do not infer exact lore, mechanical geometry, physical colliders or future special attacks from the image.
3. Produce independently editable native pixel-art sources using the project's `scripts/pixelart/` workflow. Passing a concept image through nearest-neighbor downscaling does **not** create approved sprite assets.
4. Run silhouette/readability review at 640x360 and 640x400 with approved actual protagonists, not regenerated character likenesses. Keep original sources and provenance/checksums.
5. Obtain independent top-tier art review and owner approval for visual direction before treating this reference as frozen art.
