# Floor 03 — Complete visual design reference bundle (PR #246)

This package combines the three **original exploration** packs for The Over City, Grimaldi's circus and the Skyfowl/Doomsday final act. Extract it **at the repository root** while working on `design/f03-over-city-bible` (PR #246); files are already arranged below `assets/concept/floor-03/`. It does not change any existing code, scene data, approved character source or sprites.

## Contents

- `over_city_first_key.png`: large establishing Over City atmosphere; `chapter_overview_mobile.html`: six-chapter mobile offline storyboard.
- `circus/big_top_environment_mood.png`: Big Top lighting/composition reference; `circus/circus_sequence_mobile.html`: circus stage walkthrough and interactive scene mockup.
- `skyfowl-doomsday/f03_city_false_harmony_original_concept.png`: Skyfowl settlement and pre-explosion city mood; `skyfowl-doomsday/scene_storyboard_mobile.html`: S07–S12 interactive stage walkthrough.
- Original `README`, `provenance`, and `SHA256SUMS` files from each separate pack are preserved intact.
- `BUNDLE_MANIFEST.json` records every imported member and its SHA-256.

## Approval and safety boundary

**All illustrations are conceptual art only**: not native 640x360/400 game captures, production-ready pixel masters, visually approved hero design, tested enemy silhouettes or a claim of commercial/distribution rights. No inaccurate Carl/Donut class infographic is included. The circled humanoid clown-like Grimaldi reference is atmospheric only: the accepted eventual enemy should read primarily as a **rooted Pestiferous Vine**, subject to artistic and source review. Carl, Donut and Mongo always follow their existing approved source-art identities, never generated visual approximations.

Before adopting anything in a playable build, create original editable native sprites, preserve provenance, run the pixel-art pipeline, validate source export and 1x silhouette, review independent art, and ensure usage rights permit the intended distribution. The same goes for any imported audio: none is included.
