## How AI agents must use it

- Use the reference to preserve **the same character identity** over four stages: ordinary-looking man, messy short brown hair becoming gradually fuller, expressive/irritated face, slight functional strength progression, heart-print boxers, practical mismatched gear.
- Preserve the cross-project **grimy 1980s–1990s everyman action antihero** tone, balanced with dark humor.
- Treat any accidental AI-illustrated prop, text, facial hair, cigarette, item placement or exaggerated abdominal shading as **unapproved noise** until confirmed by the design bible and book evidence.
- **Do not prompt each sprite frame as a standalone character.** Establish an editable canonical sprite source and consistent palette, pivot, proportions, and animation tags first.
- Do not assume this detailed concept sheet's apparent pixel resolution matches the **640×360 virtual camera**. Validate a ~48–56 virtual-pixel-tall Carl (provisional), including 4K integer scaling.
- Do not silently replace the approved concept reference. Submit a separate review for a revised canonical image.
