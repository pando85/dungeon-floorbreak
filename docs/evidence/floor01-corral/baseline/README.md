# CORRAL-EVAL baseline evidence (reflex absent)

Generated by the CORRAL-EVAL core evaluator (CORRAL-AUTO-01) on source commit `d2747d7334aee7db81a579966893c472bf4f8de0`, policy version 1, horizon 1,800 ticks, 6,090 runs.

**Label: reflex absent.** DM-B (Donut's post-biscuit reflex) is not on main, so every `reflex` variant run is `blocked` and the reflex gate is `blocked`, never `pass`. This is the KC13 baseline: evidence JSON from a run before DM-B, not a pinned hash.

**Stages are baselines, not the Infernal Corral.** They run on the corridor kit with today's llamas (no rush, no party targeting, no cover). The M2 stationary gate (KC19) is report-only until CORRAL-C and fails here by design: every llama aims at Carl, so a Donut-only seat is never targeted.

| File | Content |
| --- | --- |
| [`summary.json`](summary.json) | Gate outcomes, the global best counterexample, the failing groups and the per stage, seat, policy and evasion tallies |
| [`report.md`](report.md) | The same, generated as a readable report |

`runs.csv` (one row per run, about 1.3 MB) is not committed; regenerate it with the command below.

Reproduce from a fresh checkout (about 3 s of run time after the build; no Python, GPU or trained policy):

```bash
cargo run --release --locked --bin corral_eval -- --out target/corral-eval
cargo test --locked corral_auto -- --nocapture
```

No pinned hash is claimed: the evaluator's determinism check compares two in-process runs.
