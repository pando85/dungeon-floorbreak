# CORRAL-C evidence: the STATIONARY-DONUT gate on the Infernal Corral

Generated by the CORRAL-AUTO evaluator (`corral_eval`, policy version 2) on the CORRAL-C head: horizon 1,800 ticks, 21,384 runs, about 9 s of release run time on 8 worker threads. No Python, GPU or trained policy.

**What ran.** Room 0 on its real geometry (`assets/levels/floor01/f01_corral.room.json`: the pen floor, the 32 px entry shelf, the 80 px dock bumper and the 32 px exit dock), with the CORRAL-B rush and llama party targeting:

- `corral_m1`: the first llama at 848, no rush profile (CRL-Q27);
- `corral_m2`: rush llama B on the pen floor (home 1488, leash 1248..1830) and rush llama A on the dock (home 1968, leash 1920..2016), both dormant until the CRL-Q24 wake.

The sweep covers the named starts M1-A, M1-B and M2-01..M2-13 (M2-06 needs the partition), the M2-G grid, both facings, the attack phases P0..P2 (CRL-Q36), the reflex `off` and `reflex` variants, the parked-Carl decisive seat and the companion seat, every gated static policy (`stationary_cast`, `_burst`, `_aimed`, `stationary_turret`, `stationary_jump_cast` at every offset -3..52 on the named starts and `aimed`), and the mobile, Carl melee and co-op runs. The corridor baselines of CORRAL-EVAL core are the "before" half of the report.

**Not run here (run by CORRAL-D, see [`../corral-d/`](../corral-d/README.md); policy version 3 adds them).** The partition variants `intact` and `broken` and the M2-06 partition-top start; the stuck-enemy check (no progress definition for a llama that legitimately holds); live sessions, PLAYTRACE verify and native captures (CORRAL-F).

**What is asserted.** The `corral_auto_the_corral_gate_passes` test asserts every corral gate on the whole corral half of this sweep (every named start with every jump offset, the M2-G grid, both facings, P0..P2, both reflex variants, the decisive and reported seats; about 20,000 runs, about 25 s in a debug test build). Only the corridor baselines are report-only. `corral_auto_the_corral_gate_can_fail` feeds the same gate synthetic records that breach KC19 and CRL-Q35 and asserts it fails.

**Result.** Every corral gate passes: the M1 positive control (three bolts, 0 damage), KC19 on the decisive variant (0 failing of 2,122 groups), the CRL-Q35 geometric invariant, a mobile Donut, a Carl melee and a 2P co-op victory, and no hard system failure. No tuning was needed: the CORRAL-0 values and geometry pass as authored. The diagnostic `layer_static_clear` (a static Donut defeats the llama of her own level, open question 3 of the sheet) is reported: 3,204 of 12,732 gated parked M2 runs, all of them one-level kills: 2,544 floor runs defeat B and 660 dock runs defeat A; the shelf and the bumper top never clear (the breakdown by start is in the report). The diagnostic `donut_level_changes` (a knock landing on another level, sheet section 10 erratum) is reported: 270 parked jump-cast runs per reflex variant, all at x 1248 and 1280, where B's rush knocks a hopping Donut onto the entry shelf. The shelf reaches no llama, so the gate and the invariant hold.
