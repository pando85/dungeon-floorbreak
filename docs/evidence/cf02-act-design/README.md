# CF02 ACT-DESIGN evidence: acting key poses

Key-pose previews for [the CF02 acting spec](../../02-art/cf02-acting-spec.md). Rendered nearest-neighbour from the committed `cf02_keys` grids on a flat `#2a2a3a` background; no lighting, no VFX. They show the keys only: the derived frames, contact sheets of the full sheets, timing GIFs and in-scene captures belong to the execution PRs (ART-CARL-CF02, ART-DONUT-CF02, ART-GOB-CF02), which regenerate their evidence with the pixel-art toolkit.
