# ANIM-CARL-02 evidence: Carl unarmed melee, full set

Review renders of all 24 frames of the [design spec](../../02-art/carl-melee-anim-02-spec.md): 8 key poses drawn by Claude Opus (design phase and fix rounds) and 16 frames drawn by Claude Sonnet (execution). Not owner-approved, not Bevy captures (runtime integration is not done). All files except the two `goblin36_contact_*` images (see below) are regenerated by:

```sh
bash scripts/export_assets.sh
python3 scripts/make_carl_melee_previews.py   # writes generated/art/carl_melee/
```

They are copied here unchanged. `SHA256SUMS` lists their hashes; `measurements.json` records per-frame bounding boxes, contact rows and durations. The grid itself is rewritten deterministically by `python3 scripts/author_carl_melee.py` (`--check` verifies the committed grid).

GIF timing: a GIF stores 10 ms steps, a tick is 16.67 ms. Each frame is shown for its tick count, with the boundaries rounded at the cumulative tick position (never more than 5 ms off, no drift over a move). Each GIF ends with 24 ticks of the approved idle frame so the loop boundary reads; that tail is not part of the move.

The goblin silhouettes are neutral grey placeholders for scale and contact only, not goblin art. The environment kit is the approved, unchanged ENV-01 kit.
