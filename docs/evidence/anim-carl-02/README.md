# ANIM-CARL-02 evidence: Carl unarmed melee, phase 1 keys

Phase 1 (design, Claude Opus) review renders of the four key poses in the [design spec](../../02-art/carl-melee-anim-02-spec.md). Not owner-approved, not Bevy captures (runtime integration is not done). All files are regenerated by:

```sh
bash scripts/export_assets.sh
python3 scripts/make_carl_melee_previews.py   # writes generated/art/carl_melee/
```

They are copied here unchanged. `SHA256SUMS` lists their hashes; `measurements.json` records per-frame bounding boxes, contact rows and durations.

| File | What it shows |
| --- | --- |
| `key_poses_x1.png` | the approved idle (reference) and the four keys at native size: jab contact, kick wind-up, kick contact, hurt impact |
| `key_poses_x6.png` | the same at x6 with move, frame name, tick window and hit tick, the floor line (cyan), the pivot (yellow) and the art reach from the manifest (red: fist / Croc sole, magenta: whole kicking leg) |
| `timing_diagram.png` | the tick contract of all six moves drawn from the manifest `melee.moves` block: startup / active / recovery / reaction per frame, Opus keys outlined in yellow, active ticks (red bar), hit tick (red marker), jab cancel buffer and earliest chained start (cyan) |
| `floor01_kick_640x360.png`, `floor01_kick_1920x1080.png` | the kick contact key in the lit Floor 1 corridor (A1 compositor, `scripts/env_kit_light.py`) next to two grey goblin-sized placeholder silhouettes (40 px, 30 px apart; CP-02 setup). The Croc sole touches goblin A at the manifest reach (+21 px). 640 x 360 and exact 3x 1080p |
| `floor01_kick_crop_x6.png` | a 160 x 90 virtual-pixel window around the action, cut from the 1080p render and enlarged to x6 |
| `measurements.json` | per-frame bbox, opaque size, lowest row, durations, file hashes |

The goblin silhouettes are neutral grey placeholders for scale and contact only, not goblin art. The environment kit is the approved, unchanged ENV-01 kit.
