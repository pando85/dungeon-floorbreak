# GOB-02-DEATH evidence (design stage and executor pass)

Spec: [gob-02-death-spec.md](../../02-art/gob-02-death-spec.md). The first three rows were generated by `python3 scripts/author_gob02_death.py scale` (design stage); the rest by the executor pass. All are stills composed from the committed pixel-grid sources, not Bevy captures, and not a feel approval.

**Prerequisite:** the lit scenes and the toolkit evidence need the Floor 1 kit atlases and the two death atlases under `generated/art`, which are git-ignored. Run `bash scripts/export_assets.sh` once in a fresh checkout first. Then `python3 scripts/gob02_death_evidence.py` regenerates the executor stills, and `python3 -m scripts.pixelart evidence assets/source/characters/goblin/death/goblin_a_death_h36.pixelart.json --out docs/evidence/gob-02-death/poses` (and the `parts` config with `--out .../parts`) the toolkit output.
