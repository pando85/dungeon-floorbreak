# Contributing

This project is in **documentation-only concept stage**, publicly readable but **not yet licensed for open-source contributions**. Before sending code or visual content, discuss licensing and ownership with the repository maintainer. Do not add third-party franchise material or secrets.

Proposed agent contribution workflow: read `AGENTS.md`, select a `WORK-###` issue, write code/data with a reproducible test, open a small PR referencing acceptance criteria, attach evidence and request human game-feel/art review. All discussion, commits and docs are in English.

No CI or PR history should be described as passing until actually run. `python3 scripts/check_docs.py` is the only implemented check in the documentation skeleton.
